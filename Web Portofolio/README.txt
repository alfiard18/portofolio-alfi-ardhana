ALFI ARDHANA — IT PORTFOLIO
===========================

CARA MENJALANKAN
1. Ekstrak folder/file ZIP jika masih dalam bentuk ZIP.
2. Buka index.html menggunakan browser modern (Chrome, Edge, Firefox, atau Safari).
3. Pastikan file style.css, script.js, dan folder assets tetap berada di lokasi yang sama.

ISI PAKET
- index.html              Struktur website
- style.css               Tampilan, layout responsif, animasi, dan mockup proyek
- script.js               Navigasi mobile, animasi reveal, filter proyek, dan modal detail
- assets/Alfi-Ardhana-CV.pdf  CV yang ditautkan pada tombol "Lihat CV"

CATATAN KUSTOMISASI
- Email, nomor WhatsApp, pengalaman, pendidikan, dan proyek mengacu pada CV yang diberikan.
- URL LinkedIn pada halaman mengarah ke pencarian nama "Alfi Ardhana" karena URL profil spesifik tidak tercantum di CV. Ganti URL tersebut dengan tautan profil LinkedIn pribadi yang benar jika tersedia.
- Preview proyek adalah ilustrasi konsep buatan CSS/HTML, bukan screenshot produk asli. Kamu bisa menggantinya dengan screenshot asli di kemudian hari.
- Font Google Fonts memerlukan koneksi internet; website tetap menggunakan font fallback jika tidak tersedia.
